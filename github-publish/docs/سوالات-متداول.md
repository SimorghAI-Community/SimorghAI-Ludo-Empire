# سؤال‌های پرتکرار

**بازی رایگان است؟**
بله، کاملاً. سکه‌ها فقط برای بخش‌های آنلاین‌اند و خریدشان اختیاری است.

**چرا در گوگل‌پلی نیست؟**
فعلاً از همین‌جا (GitHub Releases) پخش می‌شود تا بازخوردِ اولیه جمع شود.

**نصب از APK امن است؟**
فایل با کلیدِ ثابتِ سازنده امضا شده. می‌توانی درستی‌اش را با SHA-256 بررسی کنی
(عدد در هر Release نوشته شده):

```powershell
Get-FileHash LudoEmpire-v1.0.4.apk -Algorithm SHA256
```

اثر انگشتِ گواهیِ امضا (باید در همهٔ نسخه‌ها یکی باشد):

```
SHA-256: <اینجا خروجیِ  apksigner verify --print-certs  را بگذار>
```

**اینترنت لازم است؟**
فقط برای حالت‌های آنلاین. بازی با کامپیوتر، بازیِ محلی، بلوتوث و مار و پله آفلاین کار می‌کنند.

**کمینه نسخهٔ اندروید؟**
۷.۰ (API 24).

**«حریف پیدا نشد» یا حریف مشکوک به ربات است؟**
اگر بازیکنِ واقعیِ هم‌سطح آنلاین نباشد، یک باتِ حرفه‌ای با نام و رتبهٔ یک کاربرِ واقعی
وارد می‌شود تا معطل نمانی. این بات‌ها قوی بازی می‌کنند.

**پیشرفتم بینِ گوشی‌ها همگام می‌شود؟**
بله، با همان حسابِ کاربری روی هر گوشی وارد شو.
