# حریم خصوصی

خلاصه: حالت‌های آفلاین هیچ داده‌ای بیرون نمی‌فرستند. بخشِ آنلاین فقط چیزهایی را می‌فرستد که
برای بازی لازم است.

## چه داده‌ای رد و بدل می‌شود؟
- **حسابِ کاربری:** نام کاربری و رمز (رمز درهم‌سازی‌شده ذخیره می‌شود). ایمیل و شمارهٔ تلفن لازم نیست.
- **حینِ بازیِ آنلاین:** حرکت‌ها، پرتابِ تاس، ایموجی‌ها، و وضعیتِ تخته — بینِ گوشیِ شما و سرورِ بازی.
- **رتبه و آمار:** برد/باخت، امتیازِ رتبه، دستاوردها، عضویتِ کلن.
- **پرداختِ سکه (اختیاری):** از درگاهِ زرین‌پال انجام می‌شود؛ اطلاعاتِ کارت هیچ‌وقت واردِ اپ نمی‌شود.

## دسترسی‌های اپ و دلیلشان
| دسترسی | دلیل |
|---|---|
| اینترنت | بازیِ آنلاین، ورود، جدول‌ها |
| اعلان‌ها | خبرِ «حریف پیدا شد» وقتی اپ در پس‌زمینه است |
| لرزش | بازخوردِ لمسیِ نوبت و رویدادها |
| بلوتوث و وای‌فایِ نزدیک | فقط برای بازیِ محلیِ چند‌گوشی بدونِ اینترنت |
| موقعیتِ مکانی | اندروید برای «اسکنِ دستگاه‌های بلوتوث/وای‌فایِ نزدیک» این دسترسی را اجباری می‌کند. مکانِ شما خوانده، ذخیره یا ارسال نمی‌شود. |

## حالت‌های کاملاً آفلاین (بدونِ ارسالِ داده)
بازی با کامپیوتر، بازیِ محلی روی یک گوشی، بلوتوث/وای‌فایِ محلی، و مار و پله — این‌ها بدونِ
حساب و بدونِ اینترنت کار می‌کنند و چیزی به سرور نمی‌فرستند.

## حذفِ حساب
از داخلِ اپ یا با باز کردنِ یک Issue درخواست بده تا حساب و آمارِ مربوط پاک شود.
