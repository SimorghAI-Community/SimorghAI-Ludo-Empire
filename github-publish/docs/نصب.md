# راهنمای نصب

## پیش‌نیاز
- گوشیِ اندروید با نسخهٔ **۷.۰ (API 24)** یا بالاتر.
- حدود ۶۰ مگابایت فضای خالی (فایلِ نصبی ~۲۵ مگابایت است).
- برای بخش‌های آنلاین: اتصالِ اینترنت و یک حسابِ رایگان (فقط نام کاربری و رمز).

## گام‌ها
۱. از [صفحهٔ آخرین نسخه](https://github.com/SimorghAI-Community/SimorghAI-Ludo-Empire/releases/latest) فایلِ `LudoEmpire-v1.0.4.apk` را دانلود کن.
۲. فایل را باز کن. اندروید می‌گوید «برای نصب از این منبع اجازه بده».
۳. وارد تنظیماتی که باز می‌شود شو و برای همان برنامه (مرورگر یا فایل‌منیجر) گزینهٔ
   **«اجازهٔ نصب از این منبع»** را روشن کن، بعد برگرد و **نصب** را بزن.
۴. بعد از نصب، برنامه با نامِ «منچ» در لیستِ اپ‌ها می‌آید.

## به‌روزرسانی
نسخهٔ جدید را از همان صفحهٔ Releases دانلود و روی نسخهٔ قبلی نصب کن — دیتای بازی پاک
نمی‌شود چون امضای فایل یکی است.

## رفعِ مشکل
| مشکل | راه‌حل |
|---|---|
| «برنامه نصب نشد» | فضای خالی را چک کن؛ نسخهٔ قبلی را حذف و دوباره نصب کن. |
| «بستهٔ ناسازگار» | نسخهٔ اندرویدت زیرِ ۷.۰ است. |
| در بخشِ آنلاین وصل نمی‌شود | اینترنت را چک کن؛ اگر فیلترشکن روشن است خاموشش کن و دوباره امتحان کن. |
| «حریف پیدا نشد» طول می‌کشد | چند ثانیه صبر کن؛ اگر بازیکنِ واقعی نباشد یک باتِ حرفه‌ای وارد می‌شود. |
| بازیِ محلیِ بلوتوث دستگاه‌ها را نمی‌بیند | بلوتوث و «موقعیتِ مکانی» را روشن کن (اندروید برای اسکن لازم دارد) و هر دو گوشی را نزدیک هم بگیر. |

مشکلی که اینجا نبود؟ → [یک Issue باز کن](https://github.com/SimorghAI-Community/SimorghAI-Ludo-Empire/issues/new/choose).
